## 🚀 Proyek

### 💰 [FinStart](https://github.com/rizkafaridadamayanti/finstart)
Sistem akuntansi digital untuk startup — dibangun full Vue 3 native (tanpa React/JSX), dilengkapi Express dan Drizzle ORM di backend, dengan MySQL sebagai database. Sudah mencakup manajemen keuangan, migration, seeder, sampai audit kode.

`Vue 3` `Express` `MySQL` `Drizzle ORM`

### 🏨 [NusaStay](https://github.com/rizkafaridadamayanti/nusastay-frontend)
Tampilan frontend untuk platform pemesanan penginapan, dibangun pakai Vue + Vite biar development-nya cepat dan ringan.

`Vue.js` `Vite` `CSS`

### ☕ [WanaCafe](https://github.com/rizkafaridadamayanti/wanacafe)
Sistem pemesanan dan manajemen kafe berbasis Laravel — mengatur menu, transaksi, sampai data pelanggan dalam satu tempat.

`Laravel` `Blade` `MySQL`
